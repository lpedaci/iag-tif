## 2. Accesibilidad (WCAG 2.1 AA)
- [ ] Contraste de texto 4,5:1 (3:1 para texto grande y componentes) en modo normal y modo calma.
- [ ] Todo operable con teclado; foco visible; orden lógico; enlace "Saltar al contenido".
- [ ] Un solo `h1` por página, jerarquía de títulos sin saltos; landmarks `header`, `nav`, `main`, `footer`.
- [ ] Imágenes con `alt` significativo; decorativas con `alt=""`.
- [ ] Videos con subtítulos; audio con transcripción; animación con audiodescripción en texto.
- [ ] Nada se reproduce solo; sin parpadeos; `prefers-reduced-motion` respetado.
- [ ] Zoom al 200 % sin pérdida de contenido; reflow a 320 px sin scroll horizontal.
- [ ] Objetivos táctiles de al menos 44 × 44 px.
- [ ] Menú, submenú y chat con ARIA correcto y probados con lector de pantalla (NVDA o VoiceOver).
- [ ] `lang="es-AR"` y títulos de página únicos.

## 3. Técnico
- [ ] HTML válido (validator.w3.org) en todas las páginas.
- [ ] 0 enlaces rotos (internos y externos). Herramienta sugerida: `npx linkinator <url> --recurse`.
- [ ] Lighthouse mobile: Accesibilidad ≥ 95, Buenas prácticas ≥ 95, SEO ≥ 95, Rendimiento ≥ 85.
- [ ] Imágenes en WebP con fallback, `width` y `height` declarados, `loading="lazy"` debajo del pliegue.
- [ ] Rutas relativas: probar el sitio publicado en el subdirectorio de GitHub Pages, no solo en local.
- [ ] 404.html funcional.
- [ ] Sin errores en consola.
- [ ] El sitio funciona con JS desactivado salvo el chat (que muestra un mensaje alternativo con enlace a las preguntas frecuentes en texto).

## 4. Contenido
- [ ] `grep` de raya larga y raya media devuelve vacío.
- [ ] Sin `[PENDIENTE` en el sitio publicado: `grep -rn "PENDIENTE" --include=*.html --include=*.json .`
- [ ] Ningún dato de niñas o niños reales; el caso se rotula como ficticio.
- [ ] Ninguna imagen de obras de Antonio Berni ni de Bortusk Leer subida al sitio.
- [ ] Fechas, duraciones y URLs coinciden con los TP (y la fecha de la animación, con la de YouTube).
- [ ] Videos de YouTube con inserción permitida (hoy están en No listado, que funciona para insertar; el requisito de "público y accesible" es para el enlace del sitio).
- [ ] Ortografía revisada.
